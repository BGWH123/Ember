Ember 把编码练习、参考答案和学习路线放在一个桌面应用中。界面由 Tauri 2 承载，Rust 核心管理题库与学习记录；安装独立评测器后，可以在本机运行 Python/PyTorch 测试。

## 当前版本

本站对应桌面重构的开发版本。Linux 桌面与 CPU 评测模块已做本机验收；Windows、macOS 与正式更新渠道的状态见[兼容性](../reference/compatibility.md)。源码构建、模块签名和发布所需配置均在文档中列出，不提供尚未上线的下载地址。

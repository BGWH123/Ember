打开 Ember 后，可以浏览题目、学习路线与参考答案，也可以在编辑器中保存代码草稿。这些操作使用随应用打包的内容和本地数据库，不需要启动 Python。

## 评测方式

本地评测器是单独安装的模块，包含 Python、PyTorch 和题目测试。首次运行代码时启动，空闲后释放进程；下次评测会重新启动。桌面应用与模块分别更新。

也可以在设置中选择兼容的在线评测器。启用后，源码发送到指定服务，学习记录仍保存在本机。本地评测失败时不会自动切换为在线评测。

## 学习记录

完整提交通过所有测试后，题目标记为已解决。样例运行用于检查当前实现，会记录尝试，但不会将题目标记为已解决。历史提交、草稿和进度保存在当前设备，不自动同步到其他电脑。

## 开始一次练习

先按[快速开始](quickstart.mdx)打开题目。如果需要运行测试，再[安装评测器](../evaluation/install-evaluator.mdx)。评测状态及平台覆盖范围见[兼容性](../../reference/compatibility.md)。

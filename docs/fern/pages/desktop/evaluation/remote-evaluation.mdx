当前版本不提供线上评测，也没有远程地址、令牌或启用开关。执行代码请先[安装本地评测器](install-evaluator.mdx)。

## 预留范围

Rust 评测模块仅保留一个 HTTP 接口位置，源码标注“TODO：线上评测预留功能”。接口始终返回不可用，不建立连接、不发送提交源码，也不接入桌面评测调用链。

Python 远程服务及其服务端依赖已删除，不提供启动服务的命令。AI 辅助和模块下载是独立功能，不属于线上评测。

源码：[HTTP 预留接口](https://github.com/BGWH123/Ember/blob/main/crates/ember-evaluator/src/remote.rs)。
